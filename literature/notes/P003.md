## Paper ID
P003

## Title
An Empirical Comparison of Machine Learning and Deep Learning Models for Automated Fake News Detection

## Authors
Yexin Tian (College of Computing, Georgia Institute of Technology); Shuo Xu (Computer Science & Engineering Department, University of California San Diego); Yuchen Cao (Khoury College of Computer Science, Northeastern University); Zhongyan Wang (Center of Data Science, New York University); Zijing Wei (College of Liberal Arts & Sciences, University of Illinois at Urbana-Champaign). (Yexin Tian and Shuo Xu contributed equally; Zijing Wei is corresponding author.)

## Year
2025 (Received 1 June 2025; Revised 18 June 2025; Accepted 23 June 2025; Published 25 June 2025)

## Venue
Mathematics 2025, 13, 2086 (MDPI)

## DOI
https://doi.org/10.3390/math13132086

## Research Objective
To systematically and empirically benchmark classical machine learning and deep learning models for automated fake news classification, evaluating the mathematical foundations and empirical performance of five representative models across varying input richness (headline-only, content-only, and headline + content), with attention to accuracy, interpretability, and computational tradeoffs.

## Research Questions
Not Reported as explicitly numbered research questions. The stated research gap/contributions are: (1) unified benchmarking of traditional and neural NLP models across diverse input scenarios; (2) empirical insights into how input granularity (headline, content, headline + content) affects model performance and feature utilization; (3) a contextualized review/benchmarking of classical and recent transformer/hybrid models including domain generalization and data augmentation; (4) a transparent, reproducible experimental protocol with interpretable analysis of model decision criteria.

## Dataset(s)
WELFake dataset [29] (Verma et al., 2021). Integrates four open-access sources: Kaggle Fake News Dataset, McIntire Dataset, Reuters Dataset, and BuzzFeed Political News Dataset.

## Dataset Size
72,134 English-language news articles, balanced, each with binary label (1 = fake, 0 = real). Two textual columns: title (avg 12.17 words, max 72 words, 558 titles missing) and content (mostly 0–1000+ words, max ~24,000 words, 783 contents missing). Split: training 60%, validation 20%, test 20% (stratified random sampling, fixed seeds).

## Language(s)
English (WELFake is described as a collection of 72,134 English-language news articles).

## Task
Binary fake news classification (fake vs real), evaluated under three input configurations: title-only, content-only, and title + content.

## Model(s)
- Classical machine learning: Logistic Regression, Random Forest, Light Gradient Boosting Machine (LightGBM).
- Deep learning: ALBERT (albert-base-v2), Gated Recurrent Units (GRUs).
(Decision trees are described as baselines but ensemble variants are the primary analysis.)

## Architecture Type
- Logistic Regression: linear discriminative model on TF-IDF features.
- Random Forest: bagging tree ensemble.
- LightGBM: gradient boosting tree ensemble (leaf-wise splitting, histogram-based binning, second-order optimization).
- ALBERT: parameter-efficient transformer encoder (factorized embedding parameterization, cross-layer parameter sharing, SOP objective); [CLS] embedding → softmax classifier.
- GRU: recurrent neural network with gating (embedding layer → GRU layer(s) → fully connected output layer; dropout regularization).

## Preprocessing Pipeline
Unified text normalization applied to all fields:
1. Lowercasing.
2. Noise removal: URLs, HTML tags, user mentions, hashtags, punctuation, numerical digits removed via regular expressions.
3. Whitespace normalization.
4. Stopword removal using NLTK corpus.
5. Lemmatization using WordNet lemmatizer.
For Title + Content models, preprocessed title and content concatenated before feature extraction/tokenization. Entries with missing or duplicate values removed.
- Classical models: TF-IDF vectorization, up to 1000 features, unigrams + bigrams (n-gram range 1–2); vectorizer fit on training set only (to prevent leakage).
- ALBERT: default WordPiece tokenizer (HuggingFace), padded/truncated to fixed max length (e.g., 200 tokens).
- GRU: Keras Tokenizer mapping words to integer indices, padded/truncated.
Dataset partitioned into training (60%), validation (20%), test (20%) via stratified random sampling with fixed random seeds.

## Training Strategy
- Classical models tuned via exhaustive grid search over defined parameter grids, selecting best model by weighted F1-score on validation set.
- ALBERT: fine-tuned pretrained albert-base-v2; randomized search over 10 configurations, best selected by validation weighted F1.
- GRU: randomized search over 10 hyperparameter combinations, best selected by validation weighted F1.
- Weighted F1-score on validation set used as primary criterion for hyperparameter tuning and model selection; all final metrics reported on held-out test set.
- Pairwise McNemar's tests with Holm correction for statistical significance.
- Compute: Google Colab, high-RAM configuration with NVIDIA T4 GPU.

## Hyperparameters
Logistic Regression (grid search): penalty = ℓ2; C ∈ {0.01, 0.1, 1, 10, 100}; solver ∈ {liblinear, lbfgs}; class_weight ∈ {balanced, None}.
Random Forest (grid search): n_estimators ∈ {50, 100, 200}; max_depth ∈ {10, 20, None}; min_samples_split ∈ {2, 5, 10}; min_samples_leaf ∈ {1, 2, 4}; class_weight ∈ {None, balanced}.
LightGBM: gradient boosting with ℓ2 penalty on leaf weights (λ), minimum sum of Hessians per leaf, γ penalty per additional leaf (specific grid values not enumerated beyond the described regularizers).
ALBERT (randomized search, 10 configs): learning rate η log-uniform in [10^-5, 10^-4]; epochs integer in [3, 5]; dropout uniform in [0.1, 0.5]; max sequence length ~200 tokens.
GRU (randomized search, 10 configs): embedding dimension integer in [150, 250]; hidden dimension integer in [256, 768]; learning rate η log-uniform in [10^-4, 10^-3]; epochs integer in [5, 10].
TF-IDF: up to 1000 features, n-gram range 1–2.

## Evaluation Metrics
Macro-averaged Precision, Recall, F1-score, and AUC-ROC (reported on test set). Weighted F1-score used for model selection/hyperparameter tuning. McNemar's test statistic (chi-squared, 1 df) with Holm-corrected p-values for pairwise model comparison. Also training computational time (seconds).

## Baseline Models
Classical baselines (Logistic Regression, Random Forest, LightGBM) compared against deep learning models (ALBERT, GRU). Decision trees mentioned as conceptual baselines. Comparisons are internal across the five models and three input configurations.

## Main Results
Test set performance (Table 3; macro-averaged Precision / Recall / F1 / AUC-ROC):

Title only:
- Logistic Regression: 0.84 / 0.84 / 0.84 / 0.92
- Random Forest: 0.85 / 0.85 / 0.85 / 0.93
- LightGBM: 0.83 / 0.83 / 0.83 / 0.92
- ALBERT: 0.92 / 0.93 / 0.93 / 0.98
- GRU: 0.80 / 0.80 / 0.90 / 0.96

Content only:
- Logistic Regression: 0.93 / 0.93 / 0.93 / 0.98
- Random Forest: 0.92 / 0.92 / 0.92 / 0.98
- LightGBM: 0.94 / 0.94 / 0.94 / 0.98
- ALBERT: 0.97 / 0.97 / 0.97 / 1.00
- GRU: 0.97 / 0.97 / 0.97 / 1.00

Title + Content:
- Logistic Regression: 0.93 / 0.93 / 0.93 / 0.98
- Random Forest: 0.93 / 0.93 / 0.93 / 0.98
- LightGBM: 0.94 / 0.94 / 0.94 / 0.99
- ALBERT: 0.98 / 0.99 / 0.98 / 1.00
- GRU: 0.97 / 0.97 / 0.97 / 1.00

Training time (Table 2, seconds; Title Only / Content Only / Title + Content):
- Logistic Regression: 2.95 / 2.54 / 3.01
- Random Forest: 1.87 / 7.50 / 10.76
- LightGBM: 2.32 / 22.41 / 26.91
- ALBERT: 1440.69 / 2095.64 / 6489.21
- GRU: 107.16 / 211.41 / 413.48

Key findings: Transformer-based models, especially ALBERT, achieve state-of-the-art performance (macro F1 up to 0.99 with title + content); ALBERT consistently and significantly outperforms other models (McNemar's, corrected p < 0.0001 in most comparisons). Adding article content substantially improves all models. Classical ensembles remain viable for constrained/interpretable settings. In title-only, LightGBM vs Logistic Regression was the only nonsignificant difference (p = 0.33); content-only ALBERT vs GRU tied (p = 0.0000).

## Strengths
- Systematic, multi-input-granularity benchmark (title-only, content-only, title + content) filling a stated methodological gap.
- Rigorous statistical validation via pairwise McNemar's tests with Holm correction.
- Reports computational cost (training time) alongside accuracy, informing accuracy-vs-efficiency tradeoffs.
- Detailed mathematical formulations of each model and a transparent, reproducible protocol (fixed seeds, held-out test set); interpretability analysis via TF-IDF feature importance.
- Uses a large, balanced, widely-used benchmark (WELFake, 72,134 articles).

## Weaknesses
- Some reported numbers appear internally inconsistent (e.g., GRU title-only Precision/Recall 0.80/0.80 but F1 0.90), suggesting a possible typo in Table 3.
- SHAP-based interpretability for deep models could not be completed (>100 h on high-memory GPU), so neural models lack direct explanations.
- Feature-importance narrative lists differing top terms in different sections (e.g., 'said'/'image'/'washington' vs 'video'/'breaking'/'lol'), somewhat inconsistent.
- Relies exclusively on a single English dataset (WELFake); limited generalizability.
- Research questions are described only as a research gap/contributions list rather than explicit RQs.

## Limitations
Stated by the authors: (1) experiments rely exclusively on the WELFake dataset (English, four open-access sources), so generalizability to multilingual, cross-domain, or dynamic scenarios remains open; (2) WELFake is balanced whereas real-world distributions are imbalanced and shift over time (temporal/topical drift); (3) analysis limited to supervised learning (semi-supervised, unsupervised, domain adaptation, continual learning not explored); (4) deep learning models pose interpretability challenges (SHAP was computationally prohibitive—not completed after 100+ hours); (5) statistical tests are rigorous but operational evaluations (cost-sensitive metrics, deployment trials, real-world impact) were not conducted. Qualitative error sources noted: ambiguous/sarcastic/figurative/satirical language, underrepresented sources/atypical topics, and temporal drift.

## Future Work
Stated by the authors: explore semi-supervised, unsupervised, and domain-adaptation approaches, plus continual learning for evolving misinformation; develop/apply model-agnostic interpretability tools and attention-based visualization techniques; consider cost-sensitive metrics, deployment trials, and real-world impact assessments in operational settings; assess robustness in more linguistically and geographically diverse contexts; and explore hybrid systems that integrate classical machine learning with deep learning (feature-level ensembling, stacking, or model distillation) and benchmark such hybrid pipelines.

## Interesting Ideas
- Systematically varying input richness (title-only vs content-only vs title + content) to quantify the incremental value of article body vs headline.
- Pairing accuracy with McNemar's significance testing (Holm-corrected) for rigorous head-to-head model comparison.
- Reporting training-time cost per input configuration to surface accuracy-vs-efficiency tradeoffs.
- Choosing parameter-efficient ALBERT over full BERT/LLMs for a balance of accuracy, efficiency, and interpretability in a benchmark.
- Interpretability via TF-IDF feature importance for classical models; noting SHAP scalability limits for neural models.

## Possible Inspiration For Our Paper
- For the Fake News Benchmark: adopt the three-way input-granularity axis (headline / content / combined) as a standard evaluation dimension.
- Incorporate statistical-significance testing (McNemar + Holm) into the benchmark rather than reporting point metrics alone.
- Report per-model training-time/compute cost as a benchmark column (aligns with P002's cost focus).
- WELFake is a shared dataset with P002—use it as a common benchmark to enable cross-study, cross-model comparability (classical ML vs BERT/ALBERT vs GPT-4o).

## Potential Citation Usage
- Cite for evidence that ALBERT (transformer) achieves macro F1 up to 0.99 on WELFake with title + content, significantly outperforming classical ML (McNemar p < 0.0001).
- Cite for the finding that article content adds substantial predictive signal over headlines alone, and that classical ensembles remain competitive/efficient for constrained settings.
- Cite for computational-cost comparisons (ALBERT far more expensive to train than classical models) and for SHAP scalability limitations on NLP transformers.
