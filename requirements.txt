# =============================================================================
# fnb — Fake News Benchmark: runtime dependencies (Kaggle-friendly floors)
# -----------------------------------------------------------------------------
# Execution target: KAGGLE (single NVIDIA T4). The Kaggle GPU image already ships
# most of this scientific stack, often at NEWER versions than any fixed pin.
#
# Therefore we use minimum-version FLOORS (">=") here, NOT exact ("==") pins:
#   * ">=" is satisfied by Kaggle's newer builds, so `pip install -e .` leaves
#     Kaggle's torch/numpy/scikit-learn/etc. UNTOUCHED (no downgrades, no
#     torch/torchvision/torchaudio mismatch, no numpy 1.x vs 2.x breakage).
#   * pip only *adds* the packages Kaggle is missing, choosing versions
#     compatible with what's already installed.
#
# Reproducibility is captured AFTER install by freezing the resolved environment
# on the actual T4 runtime into requirements.lock.txt (`pip freeze`). On a fixed
# Kaggle image that lock file — not these floors — is the exact reproducible
# record (see ENVIRONMENT.md).
#
# Heavier / conflict-prone libraries needed only in later milestones are NOT
# installed at base. They live as optional extras in pyproject.toml and are
# installed per-stage:
#   * QLoRA (M4/M5):      pip install -e '.[llm]'          # peft, bitsandbytes
#   * Adversarial (M5):   pip install -e '.[adversarial]'  # textattack
#   * Dev tooling:        pip install -e '.[dev]'          # pytest, ruff, black
# =============================================================================
